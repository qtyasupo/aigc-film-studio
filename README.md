# AIGC 导演工作室 · AIGC Film Studio

把一个想法发展成能制作、能检查的 AIGC 影像作品。

一个面向 Codex 的独立创作 Skill，统筹编剧、导演、摄影、角色表演、视觉资产、分镜、生成方案和后期检查。用于全 AIGC 的短剧、叙事短视频与短片，支持真人感、二维动漫、三维动画、动态漫、手绘等形式。

[English](README.en.md) · [技能正文](SKILL.md) · [原创示例](examples/returning-the-key.md) · [方法来源](SOURCES.md) · [MIT](LICENSE)

## 它解决什么

让故事、表演、镜头、生成与剪辑沿着同一个意图工作。例如，“他想留下对方”会继续落实为人物的策略、对手反应、动作、空间、镜头选择与声音，随后由实际素材检验。

- **从点子进入**：发展人物、冲突、故事与剧本。
- **从已有剧本进入**：建立视觉方向、资产、调度与镜头方案。
- **从制作进入**：准备参考、关键帧、图片/视频/声音任务，连接当前环境可用的工具。
- **从素材进入**：检查实际结果、定位问题，给出或执行范围内的修订与后期方案。

可以只完成一个环节。技能不会因为用户说“优化这段对白”就强制建立全套工程，也不会给每个短视频机械套满三幕或固定反转次数。

## 它怎样执行

本仓库提供指令、参考、模板和示例，**不内置生成引擎、API 密钥、模型、付费额度或剪辑程序**。

只有文本能力时，可以完成创作与制作交接；宿主连接了相应工具并具备用户授权时，可以编排生图、视频、音频和后期任务。实际执行能力取决于当前工具，不能仅靠安装此 Skill 获得。

用户说“只给提示词”就只输出提示词；要求生成时遵循已有授权和约定预算。生成任务成功、素材可用、完整观看/听辨和成片合格会分别说明。

## 安装到 Codex

此仓库根目录就是 Skill 目录。下载仓库或发行压缩包后，将整个 `aigc-film-studio` 文件夹放入技能目录，保留内部结构：

```text
~/.codex/skills/aigc-film-studio/
├── SKILL.md
├── agents/openai.yaml
├── references/
├── assets/
└── ...
```

Windows 默认位置是 `%USERPROFILE%\.codex\skills\aigc-film-studio`；自定义了 Codex 主目录时使用自己的技能目录。让宿主重新加载技能，再使用调用名 `$aigc-film-studio`。已有同名技能时先保留备份，不直接覆盖本机修改。

不依赖其他 Skill，不要求预装某一家媒体服务。`agents/openai.yaml` 提供 Codex 的界面信息；其他支持 `SKILL.md` 的代理可参考使用，兼容性需要在相应宿主另行验证。

## 使用示例

```text
用 $aigc-film-studio，把“一个修伞人等来了多年没见的女儿”
发展成约 60 秒的真人感 AIGC 短片。先给故事方案和剧本，不生成媒体。
```

```text
用 $aigc-film-studio，把我提供的剧本做成二维动漫分镜。
保持剧情与对白，明确人物调度、镜头目的和动作衔接；先不写模型参数。
```

```text
用 $aigc-film-studio，检查这三个生成片段能否接成一场戏。
只评价实际看得到的内容，不修改或重生成素材。
```

```text
用 $aigc-film-studio，依据已采用的镜头方案制作素材。
先检查当前可用工具；生成范围与额度沿用我在本会话确认的安排。
```

## 方法与贡献

本技能用原创表述整合通用戏剧方法及卢米特、卡茨、韦斯顿等创作资料中的相关思想，再针对 AIGC 做执行转译。它不是三位作者共同编写的教程，也不表示获得其背书。详见 [SOURCES.md](SOURCES.md)。

欢迎提交真实用例、失败证据和定点改进。改动时保留用户意图与已有选择，区分建议、实际执行和验证；涉及工具参数时提供可复查依据。提交材料不要包含凭据、私人项目或无权公开的第三方素材。行为检查关注是否作出正确决定，不要求输出与示例逐字相同。
