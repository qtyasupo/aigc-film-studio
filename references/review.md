# 分层检查与修改

先确定评价对象及可访问证据：想法、剧本、分镜、提示词、参考图、生成片段、粗剪或最终导出。按用户请求只评价或修改相应范围。

## 各层能得出什么结论

| 对象 | 可以检查 | 不能据此宣布 |
|---|---|---|
| 剧本 | 动机、因果、信息权限、场景事件、声音意图、估算时长 | 表演自然、视频无穿帮、实际时长合格。 |
| 分镜与提示词 | 镜头目的、空间、参考职责、起止状态、动作负担与剪接计划 | 模型一定实现、画面已经清楚。 |
| 静态图或抽帧 | 可见身份、造型、构图、空间和具体帧内的状态 | 全段运动连续、对白同步或声音合格。 |
| 可观看并可听辨的视频 | 其实际覆盖的表演、运动、节奏、声画与连续性 | 未查看版本或未播放范围也通过。 |
| 最终文件 | 已执行的文件检查及观看/听辨结果 | 自动满足所有平台、版权或商业要求。 |

## 提出可修复的问题

每条问题尽量包含：位置、可见证据、对观众理解或制作的影响、建议改动和应保留的内容。区分违反已确定约束、实际实现偏差，以及审美偏好。

优先处理影响核心事件的错误，例如钥匙在交接前就到了另一人手里、反应早于刺激、线索无来源、场景结果没有发生。次要纹理或背景细节是否要修，取决于它是否影响身份、空间、信息和情绪。

修订尽量定位到负责的层：故事因果问题回剧本；空间和注意力问题回调度分镜；参考冲突回资产；生成偏差回任务或工具；节奏问题回剪辑。不要对所有问题都追加一段更长的提示词。

用户只要评价时不直接改来源。用户已授权定点修订时完成修改，不把同一授权反复变成确认环节。修改核心剧情、视觉形式或关键约束前，呈现真正需要选择的差异。

自己写完后的检查清楚称为自检。如果另有独立审查，记录它对应的准确版本；后续修改后旧结论只覆盖旧版本。不要因更换角色名称或 Skill 名称就把自检称为独立审查。
