# 制作形式与资产

## 先确定形式实际改变什么

用用户提供的参考、已有素材和表达需要选择形式。未明确时给少量有区别的方向供选择；用户已经确定形式则直接沿用，不重新拉回选型。

对当前作品说明：人物怎样跨镜识别，空间按什么逻辑组织，什么可以运动，动作允许怎样夸张，颜色与声音承担什么。画风标签可以简写，但不能替代这些选择。

## 不同形式的关注点

| 形式 | 主要关注 | 可用表达方式 |
|---|---|---|
| AIGC 真人感 | 脸和造型的稳定、自然反应、身体接触、可信光线与生活细节 | 微表情、未完成动作、身体距离、画外声；按素材能力选择复杂表演。 |
| 二维动漫 | 脸眼发结构、轮廓与色块、角色区分、姿态与线条连续性 | 关键姿态、表现性构图、适度变形、速度线、静止与运动的对比。 |
| 风格化三维 | 比例、体积、材质、重量、接触点和空间运动 | 夸张姿势与真实受力并用；关注动作前后重心和道具接触。 |
| 动态漫或限动画 | 哪些层运动、哪些保持、口型与镜头运动分工 | 持续姿态、局部循环、景层视差、声音驱动；把运动集中到需要的变化。 |
| 手绘、水墨、剪纸或定格感 | 材料/笔触的稳定、边缘、层次、节奏和必要地理 | 让材料参与表达，同时保留人物识别、关键道具和因果动作。 |

表中的方式是候选词汇，不是运动预算或视觉规则的固定配方。用户可以要求全动作二维、克制的三维或混合媒介。

混合形式先说明哪一层决定身份、空间、光、边缘和运动。例如三维角色配绘制背景，应先解决角色脚底与背景地面的接触关系。不同媒介不能各自重写同一空间事实。

## 让参考各司其职

将角色身份、造型、表演姿态、场景地理、镜头构图与画风参考区分开。一张参考可以兼任，但须说明采用哪些部分。角色图不自动决定房间布局，风格图也不自动带入参考人物、文字或剧情。

只有实际查看过的素材才能据其可见内容建立规格。文件名、用户描述和生成任务成功状态不能代替查看。

对复用资产记录必要信息：用途、稳定锚点、可变状态、当前版本、适用镜头与参考来源。规模小就用表格；需要批量复现或多人协作时再增加编号和结构化记录。

区分身份与状态。换衣服、淋湿、持物或损伤通常是同一角色的变体。固定参考不会冻结所有表演，动作也不应改变人物基本结构。道具易手、破损或消失后，要传递新状态。

## 冻结画面与连续动作

图片规格描述一个确定时刻；视频规格描述随时间发生的过程。首尾帧必须分别能成立，且中间运动在所用工具能力内。身份参考、构图参考、起始状态和结束状态不要混成同一种约束。

形态变化或非人角色先确定身体结构、接触点和环境介质，再设计动作。例如水中角色的漂浮、衣物与声场不能照搬陆地步行；不要临时增加肢体或能力去实现某个镜头。
